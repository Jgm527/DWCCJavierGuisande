# Ejemplos - Estructuras de control (DWEC)

La carpeta contiene los ejemplos de código del tema organizados por bloques:

- 01_if_else
- 02_switch
- 03_bucles
- 04_iterables
- 05_break_continue
- 06_practicos

Cada ejemplo contiene:
- index.html
- script.js

Uso:
1. Abrir la carpeta del ejemplo en VS Code.
2. Ejecutar index.html con Live Server.
3. Abrir DevTools > Console.
4. Observar el resultado y compararlo con el PDF de soluciones.

Los ejemplos que dependen de prompt() requieren interacción del usuario.
