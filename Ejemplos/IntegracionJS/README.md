# Ejemplos - Integración de JavaScript en HTML

Incluye:
1. JavaScript inline.
2. JavaScript interno.
3. JavaScript externo al final del body.
4. JavaScript externo en head sin atributos (ejemplo de error).
5. JavaScript externo en head con defer.
6. JavaScript externo en head con async.

## Cómo probarlos
1. Abre cada carpeta en VS Code.
2. Ejecuta index.html con Live Server.
3. Abre las herramientas de desarrollador y entra en la pestaña Console.
4. Pulsa el botón "Púlsame".
5. Compara el resultado con el PDF de ejemplos y resultados.

El ejemplo async puede comportarse de forma distinta según cuándo termine de descargarse script.js.
